# Simple-python-tui-operating-system
A simple pythom TUI operating system
##instructions
run main.py to run the OS  
run test_apps.py to test applications  
run user_handling.py to create default user if it some how gets deleted  
  
After running main.py you can create your profile by typing in a username then type 'C' to create the   profile, you login by typing in the username, to grant that profile file permistions login to user 'default' and open the file permitions menu to grant your profile file perms, then login to your profile and use the file perm menu to remove 'default' file perms
